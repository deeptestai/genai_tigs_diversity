# Diversity Evaluation of Stable Diffusion Models

This project evaluates the **diversity behavior of Stable Diffusion (SD) models** using distinct prompts generated by large language models (LLMs).

We conduct experiments on three widely-used datasets: **CIFAR-10**, **ImageNet**, and **CelebA-HQ**. For each dataset, we generate diverse prompts with LLMs and analyze how the SD-based models respond, aiming to measure their **diversity in generated outputs**.

### Comparison with Baseline
To quantify the effect of diverse prompts, we compare the results with a **baseline model using fixed prompts**. This comparison allows us to see how introducing varied prompts influences the diversity of generated images, providing insights into the sensitivity of SD models to prompt diversity.
## Methodology

1. Generate diverse prompts for each dataset using an LLM.
2. Feed prompts into the SD model and generate images.
3. Compute diversity metrics using pretrained models (ResNet-50, CLIP-32) to evaluate diversity at **both pixel and semantic levels**, capturing variations from low-level image details to high-level conceptual differences.
4. Compare diversity scores with the baseline model using fixed prompts.
