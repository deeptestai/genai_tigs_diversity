# Diversity Evaluation of Stable Diffusion Models

## Overview

This project investigates the diversity behavior of Stable Diffusion (SD) models under different prompt-construction strategies, focusing on the influence of prompt diversity on generated image outputs.

We conduct experiments on three widely used datasets: **CIFAR-10**, **ImageNet**, and **CelebA-HQ**. For each dataset, we use large language models (LLMs) to generate diverse prompts and examine how Stable Diffusion models respond to variations in textual conditioning.

## Objectives

The main objectives of this project are to:

1. **Evaluate output diversity:** Measure the diversity of images generated by Stable Diffusion models using different textual prompts.
2. **Investigate prompt sensitivity:** Examine how variations in LLM-generated prompts influence the visual characteristics and semantic content of generated images.
3. **Compare prompt strategies:** Quantify the differences between diverse LLM-generated prompts and a baseline approach using fixed prompts.
4. **Assess diversity at multiple levels:** Analyze generated images at both pixel and semantic levels to capture low-level visual variations and high-level conceptual differences.
5. **Study dataset effects:** Investigate whether the influence of prompt diversity varies across CIFAR-10, ImageNet, and CelebA-HQ.

## Comparison with Baseline

To quantify the effect of prompt diversity, we compare the results against a baseline model using fixed prompts. Both approaches use the same Stable Diffusion model and experimental setup, while differing in their prompt-construction strategies.

This comparison helps determine whether introducing diverse prompts leads to greater diversity in generated images and provides insights into the sensitivity of Stable Diffusion models to textual conditioning.

## Methodology

1. **Prompt Generation:** Generate diverse prompts for each dataset using an LLM.
2. **Image Generation:** Feed the generated prompts into the Stable Diffusion model to produce images.
3. **Diversity Measurement:** Compute diversity metrics using pretrained models, including ResNet-50 and CLIP-32, to evaluate diversity at:
   - **Pixel level:** Capture variations in low-level visual details.
   - **Semantic level:** Capture differences in high-level visual and conceptual content.
4. **Baseline Comparison:** Compare the diversity scores obtained using LLM-generated prompts against those obtained using fixed prompts.
5. **Cross-Dataset Analysis:** Examine the results across CIFAR-10, ImageNet, and CelebA-HQ to understand how dataset characteristics affect the observed diversity.

## Datasets

- **CIFAR-10**
- **ImageNet**
- **CelebA-HQ**
